Description

This task adds a client to the client table in CheckPoint. It needs the following inputs: 'client_name:address:email:website:phone:fax' in ARGS field. Only client name is required. The others are optional.


Variable Description
client_name Client name
address Client address
email Client email address
website Client website
phone Client phone number
fax Client fax number

Examples

Input Description
Client A Creates a record in client table for 'Client A'
ORS:/ors.com Create a record for ORS and add website info
